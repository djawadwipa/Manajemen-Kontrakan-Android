# Kebijakan Privasi — Manajemen Kontrakan

Tanggal berlaku: 30 Juli 2026

Manajemen Kontrakan adalah aplikasi offline. Aplikasi tidak membuat akun, tidak menggunakan server, tidak menggunakan analitik, tidak menampilkan iklan, dan tidak mengirim data kepada pengembang atau pihak ketiga.

Data unit, penyewa, tagihan, pembayaran, pengeluaran, dan laporan disimpan hanya di database privat aplikasi pada perangkat. Android cloud backup dinonaktifkan. Pengguna dapat mengekspor data secara manual melalui pemilih dokumen Android. File backup dienkripsi menggunakan kata sandi yang ditentukan pengguna; kata sandi tersebut tidak disimpan oleh aplikasi.

Aplikasi tidak meminta izin lokasi, kamera, kontak, telepon, mikrofon, notifikasi, atau akses penyimpanan luas. Aplikasi tidak memiliki izin internet.

Pengguna bertanggung jawab menjaga keamanan perangkat, file ekspor, file backup, serta kata sandi backup. Menghapus aplikasi akan menghapus database lokal kecuali pengguna telah membuat backup manual.
